Current Weak Points

Recommended Next Controls

1. GPG / Sigstore Signature

証拠の発行者を検証し、Origin Scoreを 0.80 → 0.95 へ引き上げる。

2. YubiKey-backed Signing

秘密鍵をPC外に置き、署名の信頼性をさらに強化する。

3. OpenTimestamps / Bitcoin Anchor

証拠がその時点で存在したことを外部時刻で固定する。

4. SQLite Audit Log

検証履歴を保存し、監査・検索・CSV/JSONエクスポートに対応する。

5. Verification API

企業のAIログ基盤・SOC・監査システムに組み込める形にする。

6. Evidence Package Export

HTML / JSON / SHA256 の提出用レポートパッケージを生成する。
