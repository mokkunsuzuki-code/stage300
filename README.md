# Stage300: AI Vulnerability Verification Demo

Stage300 is the public showcase for the Stage299 Gate engine.

It demonstrates the following flow:

```text
AI vulnerability evidence
→ manifest
→ Stage299 Gate
→ accept
What This Stage Shows

Stage299 created the Gate engine.

Stage300 shows how that Gate can be used for an AI vulnerability verification URL.

Important Safety Note

This repository uses a safe simulated AI vulnerability record.

It does not include working exploit instructions.

Why This Matters

Raw AI outputs are easy to copy, alter, or misrepresent.

Stage300 converts an AI vulnerability record into verifiable evidence.

The result can be checked by a Gate:

evidence exists
evidence is hashed
evidence has a manifest
evidence passes the decision layer
Decision

The demo manifest passes the Stage299 Gate and returns:

accept
Stage Role
Stage299 = Gate engine
Stage300 = AI vulnerability verification showcase
